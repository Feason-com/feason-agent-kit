# Contributing

Thank you for helping agents support careful reading of the Gospels.

## Before opening a pull request

1. Keep Matthew, Mark, Luke, and John independently useful. Do not replace the
   four profiles with one harmonized profile.
2. Ground factual or theological changes in named, inspectable sources.
3. Label disputed interpretations and represent major Christian traditions
   fairly instead of treating one perspective as universal.
4. Do not add copyrighted Scripture text or commentary without recording its
   license and required attribution.
5. Run `npm run check`.

## Review requirements

- Code changes require maintainer review.
- Profile, safeguard, or theological-language changes require a named human
  theological reviewer before release.
- Security vulnerabilities should follow `SECURITY.md`, not a public issue.
